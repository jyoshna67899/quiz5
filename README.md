# QuizMaster CRT — Version 2

A GitHub Pages-only degree placement and CRT practice platform.

## What changed
- Replaced placeholder options such as `Concept A` and `See explanation`.
- Questions now use meaningful, topic-specific answers and distractors.
- Added **30 seconds / 1 minute / 2 minutes per question**.
- Timer follows the selected time mode.
- Time-up automatically reveals the correct answer and explanation.
- Supportive feedback is shown after incorrect answers.
- All Subjects, All Levels and All Companies continue to work as combined filters.

## GitHub Pages
Upload these four files to the root of your repository:
- index.html
- style.css
- app.js
- questions.js

Then GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

No backend, database, API key or server is required.
